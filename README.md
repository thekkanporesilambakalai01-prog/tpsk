# TPSK website (static, GitHub Pages ready)

Open `index.html`, or upload this whole folder to a GitHub repository and enable Pages (Settings → Pages → deploy from branch, root).

## Where to edit (everything is in data/site-data.js)
- Gallery photos: put files in `assets/images/gallery/`, add each file name to the `gallery` list. Start a file name with `pin-` to feature it at the top.
- Downloads (rules and regulations, entry form, brochure): put files in `assets/downloads/`, add `["Title", "file.pdf"],` to the `downloads` list.
- Phone numbers, Instagram, locations, Tamil academy name: same file.
- Hero photo: save a wide photo as `assets/images/hero/hero.jpg`.
- Enquiry form: sends the enquiry to the chosen branch on WhatsApp (no setup needed).
